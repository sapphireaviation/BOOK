# Branding shortlist

The product name is a single env var (`NEXT_PUBLIC_SITE_NAME`), so picking a name does not need code changes.

Domain availability could not be checked from the build environment (the registrar API and RDAP were not reachable). Check each before deciding.

| Name | Idea | Domains to check |
| --- | --- | --- |
| Plainfare | The fare, plainly, nothing added | plainfare.com, plainfare.in, plainfare.travel |
| Nilfee | Says the promise in four letters; reads well in Indian English | nilfee.com, nilfee.in |
| Raahi | Hindi and Urdu for traveller; short, warm, India first | raahi.travel, raahi.in, goraahi.com |
| Safarly | From safar (journey) | safarly.com, safarly.in |
| Wayline | Wayfinding line, matches the visual identity | wayline.travel, wayline.in |
| Truefare | The real price | truefare.in, truefare.travel |
| Zerocut | Hosts keep everything; nobody takes a cut | zerocut.travel, zerocut.in |

Criteria: say it once and spell it, works in Hindi and English, no clash with an existing travel brand in India (check the trademark registry at ipindia.gov.in), `.com` or `.in` available.
